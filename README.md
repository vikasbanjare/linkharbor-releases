# LinkHarbor for Mac

Downloads for LinkHarbor, a Mac app that saves videos, images and audio from links.

- **Install:** open the latest release, download `LinkHarbor-<version>.dmg`, drag LinkHarbor to Applications. The first time, macOS asks you to confirm: System Settings → Privacy & Security → **Open Anyway**.
- **Updates:** installed copies update themselves. Every few hours LinkHarbor reads `latest.json` here, downloads a newer version, checks its signature, and installs it the next time the app quits.

Apple Silicon Macs (M1 or newer), macOS 14 or later. Download only media you have permission to save.
